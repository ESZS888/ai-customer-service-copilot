# 三分钟演示

1. 买家页输入“你们有什么产品？”、“P001多少钱？”或“查询 ORD-001 的金额和物流”。说明这些是演示资料。
2. 输入“演示投诉：ORD-001 耳机有杂音，请记录工单，暂不退款”。核对回复和卡片编号一致，显示保存后再确认。
3. 点击商家详情链接，查看原话、AI 草稿和用户提供的订单编号。先保存“处理中”，再填写演示处理说明并标记“已处理”。
4. 刷新、停止并重启后端，确认编号、状态和历史仍在。
5. Dashboard 选择“演示交互”，核对本次咨询与工单。真实回归运行后切换“评测数据”，说明其不是买家业务量。选择无数据的日期查看空态。
